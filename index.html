1. Multiplayer connection details

Important info:

  • 1. We are not using dedicated servers for this game; instead, matches are hosted on players' computers. Thus, connection is essentially P2P as [player <-> room host], or in worst case scenario, P2P via relay as [player <-> master server <-> room host].
  • 2. After joining the room, wait a few seconds before pressing the 'Start' button. This improves the chances of establishing a direct P2P connection without relay.
  • 3. Radmin VPN is supported. If you and your friends are in the same emulated local network, the connection will go through it, reducing the ping in some cases.
  • 4. Please avoid becoming the room host if your PC is low-end and runs the game at only 10 FPS, as this will result in a poor experience for other players joining your game.

You can see your connection type next to the radar:

If you see a 'Relay' when playing with known friends, give Radmin VPN a try as it may help establishing direct P2P connection and reduce the ping.

2. Game results screen gacha

You can open 1 box out of 3 after finishing the game if you fulfil the following conditions:

  • Played Wave Defense game mode and reached rank higher than "D".
  • Played any other game mode (bot modes included) for at least 4 minutes.

The gacha reward is randomly selected from the weapons parts you have not unboxed yet:

  • [Camo Navy] Weapon parts.
  • [Creature] Weapon parts.
  • [DNA] Weapon parts.

In total 133 weapons parts that can be used to build 19 weapons presets. After you unbox all weapon parts, you'll start receiving a random amount of Points from gacha boxes.

3. Wave Defense info

The game mode final rank is based NOT on the wave you just finished, but on the wave you just started. The ranks are just there for the visual representation of how far you have advanced.

  • Wave 0-5: Rank "D". Fail, cannot play the gacha.
  • Wave 6: Rank "C".
  • Wave 11: Rank "B".
  • Wave 16: Rank "A".
  • Wave 21: Rank "S". Game won, and all next waves are infinite.
  • Wave 23: Rank "SS".
  • Wave 25: Rank "SSS".

4. KDH & WLD saving

Kills/Deaths/Headshots and Wins/Loses/Draws are saved to you stats in the following game modes:

  • Team Deathmatch. AI Bot modes not included.
  • Bomb (Demolition). AI Bot modes not included.
  • Domination.

[Overall]

1) Added a highly requested feature to customize the characters and weapons bots use.

  • • To customize, open the file "SA2Game\Script\BotSettings.js" in any text editor and make the desired changes.
  • • At the top of the file, you'll find a list of possible items for each equipment category.
  • • Bots will randomly select an item ID from the provided list.
  • • Example: "RedCharacter = [58]" means all Red team bots will always select item ID 58 = [F] Miya (RED).
  • • If you use an item ID that is not supported or make the list empty, an entire file will be silently ignored and default settings will be used.

2) If "Sniper Rifle only" restriction is set, bots will no longer ignore it.

[Minor tweaks]

About Sudden Attack 2

Sudden Attack 2 is a free-to-play multiplayer first-person shooter game developed by Nexon GT as a sequel to the original Sudden Attack. Initially launched on July 6th, 2016. Runs on Unreal Engine 3. Satisfying visuals, weapon customization, and Zombie PVE.
