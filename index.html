About the game
Sudden Attack 2 is a free-to-play multiplayer first-person shooter game developed by Nexon GT as a sequel to the original Sudden Attack.

It runs on Unreal Engine 3 and provides satisfying visuals even for today's standards. The game also features weapons customization system, few playable game modes.
